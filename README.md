# OBS 录屏启停弹窗提醒插件

OBS 开始/停止录制时，屏幕右上角滑出英伟达风格的提醒弹窗。

## 效果

- **开始录制**：绿色弹窗滑入，提示"屏幕录制已开始"
- **停止录制**：红色弹窗滑入，提示"屏幕录制已停止"
- 带提示音，自动消失，无需点击，不抢焦点
- 后台程序随 OBS 自动启动、自动关闭

## 安装

1. 把 `mod` 文件夹放到 OBS 安装目录里
   - Steam 版默认路径：`C:\Program Files (x86)\Steam\steamapps\common\OBS Studio\mod`
2. 打开 OBS → 工具 → 脚本
3. 点左下角 "+" → 选择 `mod/obs-recording-notify.lua`
4. 完成

## 重要：必须以管理员身份运行 OBS

右键 OBS 快捷方式 → 属性 → 兼容性 → 勾选 **"以管理员身份运行此程序"**。

否则全局录制快捷键在后台/游戏里可能不生效。

## 自定义设置

打开 `mod/配置.txt`，直接修改保存即生效，无需重启 OBS：

| 配置项 | 说明 |
|--------|------|
| 位置=右上 | 可选：右上/左上/右下/左下 |
| 边距=20 | 弹窗距屏幕边角距离（像素） |
| 停留时间=2.5 | 弹窗停留秒数 |
| 尺寸比例=100 | 弹窗大小百分比（30~300） |
| 声音=开 | 开/关 |
| 音量=80 | 提示音大小（0~100） |

## 关于全屏游戏

游戏若以"全屏独占"模式运行，Windows 不允许普通窗口盖在游戏上，弹窗会被遮挡。这是系统限制。

解决办法：
1. 游戏内使用"无边框窗口/窗口化全屏"模式
2. 保持声音=开，全屏时靠提示音知道录没录上

## 文件说明

| 文件 | 作用 |
|------|------|
| notify.exe | 弹窗主程序 |
| obs-recording-notify.lua | OBS 加载的脚本 |
| 配置.txt | 自定义设置 |
| 使用说明.txt | 详细说明 |

## 卸载

OBS 工具 → 脚本 中选中该脚本，点 "-" 移除即可。
后台程序会在 OBS 关闭时自动退出。
